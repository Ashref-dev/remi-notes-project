# Remi v1.1.0 Release Notes

## 🚀 New Features

### ✨ Model Selection Interface
- **New Groq Model Picker**: Added a modern, minimalist model selection interface with beautiful card-based UI
- **Smart Model Tags**: Each model now displays relevant tags (Creative, Coding, Generalist, etc.) for easy identification
- **Comprehensive Model Library**: Support for all major Groq models including:
  - Llama models (3.1 8B, 70B, 405B)
  - Mixtral models (8x7B, 8x22B)
  - Gemma models (7B, 9B)
  - And many more specialized models

### 🖥️ True Menu Bar Application
- **No Dock Icon**: Remi now runs as a true menu bar application without appearing in the dock
- **Improved Click Behavior**: Left-click opens Remi immediately, right-click shows the context menu
- **Custom About Dialog**: Beautiful about dialog showing "Made with ❤️ by ashref.tn"

## 🐛 Bug Fixes

### 💥 Crash Prevention
- **Fixed Preferences Window Crashes**: Resolved EXC_BAD_ACCESS errors when opening/closing preferences
- **Improved Memory Management**: Better lifecycle management for windows and UI components
- **Enhanced Stability**: Multiple crash-prone areas have been reinforced with proper error handling

### 🎨 UI/UX Improvements
- **Consistent Card Widths**: Fixed sidebar scroll bar taking up space and causing width inconsistencies
- **Hidden Scroll Indicators**: Scroll bars are now invisible but functionality remains intact
- **Perfect Alignment**: Nook cards and "Add New Nook" button now have exactly the same width

## ⚡ Performance & Technical Improvements

- **Optimized Build**: Release build with full optimization for better performance
- **Code Signing**: Properly signed application for macOS security compliance
- **Reduced Bundle Size**: Optimized assets and dependencies

## 🔧 System Requirements

- macOS 14.5 or later
- Apple Silicon (M1/M2/M3) or Intel processors
- Active internet connection for AI features

## 📦 Installation

1. Download `Remi-v1.1.0-macOS.zip`
2. Extract the ZIP file
3. Move `remi.app` to your Applications folder
4. Launch Remi from Applications or find it in your menu bar
